THE FORMAL MODEL

How the machine sorts

A visible parcel sorter built from the basic operations of a deterministic Turing machine.

COMPUTATION, MADE VISIBLE

Every swap is a sequence of machine steps

The simulator does not call a built-in sorting function. It reads one tape cell, applies one transition, writes at most one symbol, and moves its head. It repeats scans until it completes a pass without finding an out-of-order pair.

FORMAL DEFINITION

Machine tuple

M = (Q, Σ, Γ, δ, q₀, qaccept, qreject)
  • Q — finite set of control states
  • Σ — input alphabet {S, P}
  • Γ — tape alphabet {S, P, □, ⊢, ⊣}
  • δ — transition function
  • q₀ — initial state; qaccept and qreject are halting states

TRANSITION SHAPE

One rule at a time

δ(q, a) = (q′, b, D)

The machine in state q reads symbol a, writes b, moves in direction D (L, R, or S), and enters state q′.

ALGORITHM

Adjacent-swap passes

  1. Scan neighboring symbols from left to right.
  2. When the machine sees S P, write S over the P, move left, then write P over the S. These are two separate transitions and are animated separately.
  3. Remember in the finite control that this pass made a swap.
  4. At the right marker, restart if a swap happened; accept if the pass was clean.

WHY REPEAT?

Sorting one pair at a time

A single left-to-right pass might move a priority parcel left by only one cell. Repeating passes brings every P before every S. For example:

SPSP → PSSP → PSPS → PPSS

The displayed trace shows the actual transition sequence, including separate writes for each swap.

INDUSTRIAL CONNECTION

From scan to sorting lane

  1. Scan the parcel ID.
  2. Check its shipping record: priority or standard.
  3. Sort it into the matching lane.

In this simulator, the parcel class is entered as P or S. Real equipment would perform the scan and move the parcel.

Model note: ⊢ and ⊣ mark the input region so the machine knows where a pass starts and ends. The tape can display blank cells beyond these markers; for valid S/P inputs the machine stays within the marked region.
